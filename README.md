### About

I build backend systems where correctness and latency actually matter — financial audit and reconciliation platforms today, clinical lab and blood-bank systems before that. Most of my work lives in **.NET 8 / ASP.NET Core** over **PostgreSQL** and **SQL Server**, with a strong bias toward measuring before optimizing.

The problems I enjoy most: streaming large datasets without blowing up memory, pushing aggregation into the right layer instead of application code, and moving slow work off the request path.

Lately I've been spending my time on **AI-assisted development** — designing repeatable workflows with Claude Code (custom commands, subagents, skills, MCP) and shipping document-intelligence features into production pipelines.

- 🔭 Currently: backend design & delivery on a microservices audit platform
- 🌱 Learning: agentic AI systems, Kubernetes, and deeper CI/CD practice
- 💬 Happy to talk about: API design, performance profiling, testing discipline, clean architecture
- 🧑‍🏫 I lead code reviews and mentor a team of engineers
